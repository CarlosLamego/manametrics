# ManaMetrics

ManaMetrics é uma aplicação Angular para acompanhar partidas de Magic: The Gathering.

## Funcionalidades

- 📚 Cadastro de decks
- 📥 Importação de listas (.txt)
- 🃏 Integração com Scryfall
- 📊 Estatísticas de partidas
- 🏆 Histórico de eventos

## Stack

- Angular 21
- TypeScript
- Angular Material
- Scryfall API
