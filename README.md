# ManaMetrics

Aplicação desenvolvida em Angular para acompanhamento de partidas de Magic: The Gathering.

## Funcionalidades

- Cadastro de decks
- Importação de listas (.txt)
- Integração com Scryfall
- Histórico de partidas
- Estatísticas de desempenho

## Tecnologias

- Angular 21
- Angular Material
- TypeScript
- Scryfall API
